# Flikon Social

Flikon Social is a lightweight, dependency-free landing page prototype for a social media management app. It presents the product vision for a workspace that combines content planning, approvals, social inbox workflows, connected channels, and campaign analytics.

## Build

```bash
./scripts/build.sh
```

The production files are emitted to `dist/`.

## Project structure

- `index.html` provides the app shell.
- `src/main.js` renders the product page and dashboard preview.
- `src/style.css` contains the responsive visual system.
- `scripts/build.sh` creates the static production bundle.
